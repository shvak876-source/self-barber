# הספר של עצמי

אפליקציה קטנה למי שמספר את עצמו: מצלמים כל תספורת, נותנים לה ציון ורואים את השיפור לאורך זמן. כל תספורת בבית מוסיפה 60 ₪ למד החיסכון.

- לכל אחד קישור משלו: `/1/` של שלמה ו-`/2/` של ניתאי, עם תספורות וחיסכון נפרדים
- התמונות והנתונים נשמרים רק בטלפון, לא בשרת
- עובדת גם בלי אינטרנט אחרי הפתיחה הראשונה (`sw.js`)
- אפשר להוסיף למסך הבית עם לוגו (`manifest.webmanifest` בכל תיקייה)
- בלי התקנה ובלי בנייה. `1/index.html` ו-`2/index.html` הם עותקים של `index.html`
